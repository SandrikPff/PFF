# Участие в разработке

Спасибо за интерес к PFF. Перед созданием Pull Request откройте Issue с описанием предполагаемого изменения, если изменение затрагивает аудиомаршрутизацию, установщик или поведение горячих клавиш. Изменения должны сопровождаться шагами проверки на Windows 11.

Сборка и тестирование описаны в [docs/BUILD.md](docs/BUILD.md). Не включайте бинарники, локальные настройки, логи и компоненты третьих сторон в коммиты. Юридические условия передачи прав на вклад в проект следует согласовать с владельцем репозитория до публикации изменений; открытая лицензия для исходного кода пока не выбрана.
