# Безопасность

## Сообщение об уязвимостях

Не публикуйте отчёты о потенциально эксплуатируемых уязвимостях в публичных Issues до согласования способа раскрытия с сопровождающим проекта. При доступности GitHub Private Vulnerability Reporting используйте этот канал на вкладке **Security** репозитория.

## Компоненты установки

Установщик PFF скачивает сторонние аудиокомпоненты с сайтов издателей. Часть пакетов сверяется по SHA-256, а установщик VB-CABLE проверяется по цифровой подписи Windows. Перед распространением новой сборки рекомендуется проверять источник, цифровую подпись и результаты установки на тестовой системе.

Не присылайте в Issues токены, пароли, адреса электронной почты или личные данные из журналов.
