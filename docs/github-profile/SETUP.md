# GitHub profile deployment

To display a custom README on https://github.com/SandrikPff, GitHub requires a **public repository with exactly the same name as the account**: `SandrikPff/SandrikPff`.

The currently connected GitHub integration can edit an existing repository but cannot create new repositories. This branding package is therefore staged in `SandrikPff/PFF` until the profile repository exists.

1. Open https://github.com/new, set **Repository name** to `SandrikPff`, choose **Public**, select **Add a README file**, and click **Create repository**.
2. Copy `docs/github-profile/README.md` into the root of `SandrikPff/SandrikPff`, replacing its default README.
3. Copy `docs/github-profile/snake.yml` to `.github/workflows/snake.yml` in that new repository.
4. In the profile repository open **Actions → Generate contribution snake → Run workflow**. It needs Actions enabled and workflow write access to repository contents. The first run creates the `output` branch. The animation then updates automatically each day.
5. To change your profile picture, open https://github.com/settings/profile, click the current avatar, select **Upload a photo**, and choose the PFF avatar PNG.

The third-party statistics badges are rendered by external services, so may temporarily fail if those services are down or rate-limited. The snake animation is generated by a GitHub Actions workflow and hosted in your own repository.
