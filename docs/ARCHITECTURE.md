# Архитектура PFF

## Технологии

PFF — Windows-приложение на **C# / .NET 8 / WPF**, ориентированное на Windows 11 x64. Обнаружение и захват аудиоустройств реализованы через **NAudio**. Установщик создан на Inno Setup.

## Обработка наушников

1. `AudioEndpoints.cs` получает доступные конечные точки воспроизведения и записи Windows.
2. `MainWindow.xaml.cs` обрабатывает действия в интерфейсе и собирает параметры выбранного профиля.
3. `ApoProfiles.cs` формирует конфигурацию EQ, усиления, компрессора и реверберации для выхода.
4. `ApoBridge.cs` отвечает за взаимодействие с конфигурацией Equalizer APO‑XT, включая выбор устройства и служебные операции.
5. `HallImpulse.cs` генерирует импульсный отклик для эффекта реверберации.

Ограничение: системная обработка выхода зависит от того, подключён ли APO к соответствующему устройству Windows.

## Обработка микрофона

`MicrophonePipe.cs` открывает физический вход через **WASAPI Capture**, обрабатывает полученные аудиоданные и передаёт результат на выходное устройство **VB-CABLE** через **WASAPI Output**. Затем сторонние приложения (например, Discord) выбирают виртуальное устройство **CABLE Output** в качестве входа.

Это **отдельная аудиоцепочка**: выбор устройства вывода в PFF не должен менять источники входа, а настройка микрофона не должна менять EQ наушников. Для обработки голоса приложение должно оставаться запущенным.

## Интерфейс и локальное состояние

`MainWindow.xaml` и `MainWindow.xaml.cs` содержат элементы семи разделов, пресеты, таймер, секундомер, метроном, часы и обработку Raw Input для горячих клавиш. Настройки и пользовательские файлы хранятся в `%LOCALAPPDATA%\Pff_crimson` для совместимости с предыдущими версиями приложения.

## Установщик

`Installer/PFF.iss` проверяет необходимые аудиокомпоненты, загружает недостающие установочные пакеты с официальных источников и запускает их по мере необходимости. `install-mic-driver.ps1` отвечает за VB-CABLE: скачивает архив, проверяет цифровую подпись исполняемого файла и запускает мастер драйвера. Драйвер не входит в исходный репозиторий.

## Тестирование

Проект `Tests/Routing` содержит проверочную программу для логики маршрутизации и профилей. **Ручные проверки на Windows обязательны**: приложение зависит от реальных аудиоустройств, драйверов, настройки APO и конфигурации программ записи.
