## О проекте

PFF — компактное настольное приложение для управления звуком и повседневными инструментами. Панель поддерживает светлую и тёмную темы, изменение акцентного цвета, масштабирование и режим поверх остальных окон.

### Возможности

| Раздел | Описание |
|---|---|
| **Наушники** | Выбор устройства, 20 полос эквалайзера (20 Гц – 20 кГц), усиление, компрессия, реверберация, пресеты. |
| **Микрофон** | Отдельный 20-полосный эквалайзер, усиление и эффекты; вывод обработанного голоса через виртуальное аудиоустройство. |
| **Таймер** | Обратный отсчёт, звуковое уведомление, горячая клавиша, автоматический сброс. |
| **Секундомер** | Запуск, пауза и сброс, управление с клавиатуры. |
| **Метроном** | Настраиваемый темп, встроенные сигналы и пользовательские WAV. |
| **Часы и настройки** | Текущее время, оформление, звуки, горячие клавиши. |

> Обработка звука зависит от доступных аудиоустройств Windows и корректной установки сторонних компонентов. Подключение микрофона через VB-CABLE требует отдельного выбора виртуального входа в Discord или другом приложении.

## Установка

1. Откройте страницу [Releases](https://github.com/SandrikPff/PFF/releases/latest) и скачайте **`PFF_Setup.exe`** (если опубликован).
2. Запустите установщик на **Windows 11 x64**. Для установки драйверов потребуются права администратора, а для загрузки компонентов — подключение к Интернету.
3. При необходимости разрешите установку официальных сторонних компонентов. Для VB-CABLE следуйте инструкциям мастера и перезагрузите Windows, если будет предложено.
4. Запустите PFF через меню «Пуск».

**Настройка Discord:** выберите физический микрофон внутри PFF, включите обработку и установите в Discord устройство ввода **`CABLE Output (VB-Audio Virtual Cable)`**. PFF должен работать, пока нужен обработанный голос.
